{# The Taxes catalogue of the Settings Taxes tab. Rows are the same shape the Products screen's catalogue uses — code, name, rate and the active toggle, all inside one form so an edit is a single submit — with the settings surface's own action URLs. The rate is a canonical Decimal in Rust and is formatted only here, at the presentation boundary; the same request context parses it back, so a rate typed as `21,5` in Spanish is stored as `21.5` and read back as `21,5 %`. A localized value is never persisted. The hard delete is a two-step: the row's button asks the server for a confirmation panel (see partials/settings_tax_delete_confirm.html) and only that panel's form can actually delete. Nothing here deletes on one click. #}
